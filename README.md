# 🌤️ JavaScript Weather Dashboard

A **fully functional weather dashboard** built using **HTML, CSS, and JavaScript** with a clean, modern interface and essential weather-tracking features, designed to provide real-time weather information and forecasts for different locations.

---

## Features

### Basic Controls
- `Search` – allows users to search for a city or location.
- `Get Weather` – retrieves the latest weather information for the selected location.
- `Refresh` – updates the displayed weather information.

### Weather Information
- Displays the current temperature of a selected location.
- Shows weather conditions such as sunny, cloudy, rainy, and stormy.
- Provides additional details, including humidity and wind speed.
- Displays location information and corresponding weather icons.

### Additional Features
- Real-time weather updates using a weather API.
- Displays weather forecasts for upcoming days.
- Provides a clean and organized weather overview.
- Handles invalid locations and unsuccessful search requests.

---

## How It Works

The weather dashboard uses **JavaScript Fetch API** to retrieve weather information from an external weather service. It processes the returned data and dynamically updates the dashboard using DOM manipulation without reloading the page.

**Example Usage:**
1. Enter a city name in the search field.
2. Press `Search` to find the location.
3. View the current weather conditions and temperature.
4. Check additional weather details such as humidity and wind speed.
5. Browse the forecast to see upcoming weather conditions.

---

## Technologies Used
- **HTML** – structures the weather dashboard interface.
- **CSS** – styles the layout, weather cards, and overall design.
- **JavaScript** – handles API requests, weather data processing, and user interactions.
- **Weather API** – provides real-time weather information and forecasts.
